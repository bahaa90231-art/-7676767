# الأماكن 3:13 — موقع الرواية

مشروع Static HTML/CSS/JS جاهز للنشر.

الملفات:
- index.html: الصفحة الرئيسية
- reader.html: صفحة القراءة
- chapters/: صفحات الفصول
- style.css: التصميم المتجاوب
- script.js: البحث، الوضع الليلي، التقدم، التحكم بحجم الخط
- robots.txt
- sitemap.xml
- manifest.webmanifest
- assets/novel.pdf: ضع نسخة PDF الأصلية هنا قبل النشر

ملاحظة:
صفحات الفصول في هذه النسخة تحتوي على عناوين ووصف مختصر فقط. لإظهار النص الكامل حرفياً داخل صفحات الويب، استبدل محتوى كل فصل بالنص المستخرج من الرواية الأصلية.
